Cálculo 2 – Lista 3

Calcule as integrais indefinidas abaixo utilizando o Método da Substituição.

(a) $\int \cos(3x)dx$

Substituição: Seja $u = 3x$.

Diferencial: $du = 3dx \implies dx = \frac{du}{3}$.

Integral: $\int \cos(u)\frac{du}{3} = \frac{1}{3}\int \cos(u)du = \frac{1}{3}\sin(u) + C$.

Resposta: $\frac{1}{3}\sin(3x) + C$
(b) $\int x(4+x^2)^{10}dx$

Substituição: Seja $u = 4+x^2$.

Diferencial: $du = 2xdx \implies xdx = \frac{du}{2}$.

Integral: $\int u^{10}\frac{du}{2} = \frac{1}{2} \cdot \frac{u^{11}}{11} + C = \frac{u^{11}}{22} + C$.

Resposta: $\frac{(4+x^2)^{11}}{22} + C$
(c) $\int x^2\sqrt{x^3+1}dx$

Substituição: Seja $u = x^3+1$.

Diferencial: $du = 3x^2dx \implies x^2dx = \frac{du}{3}$.

Integral: $\int \sqrt{u}\frac{du}{3} = \frac{1}{3} \int u^{1/2}du = \frac{1}{3} \left( \frac{u^{3/2}}{3/2} \right) + C = \frac{2}{9}u^{3/2} + C$.

Resposta: $\frac{2}{9}(x^3+1)^{3/2} + C$
(d) $\int \frac{dt}{(1-6t)^4}$

Substituição: Seja $u = 1-6t$.

Diferencial: $du = -6dt \implies dt = \frac{du}{-6}$.

Integral: $\int u^{-4}\frac{du}{-6} = -\frac{1}{6} \left( \frac{u^{-3}}{-3} \right) + C = \frac{1}{18}u^{-3} + C$.

Resposta: $\frac{1}{18(1-6t)^3} + C$
(e) $\int \cos^3\theta \sin\theta d\theta$

Substituição: Seja $u = \cos\theta$.

Diferencial: $du = -\sin\theta d\theta \implies \sin\theta d\theta = -du$.

Integral: $\int u^3(-du) = -\int u^3du = -\frac{u^4}{4} + C$.

Resposta: $-\frac{1}{4}\cos^4\theta + C$
(f) $\int \frac{\sec^2(1/x)}{x^2}dx$

Substituição: Seja $u = \frac{1}{x} = x^{-1}$.

Diferencial: $du = -x^{-2}dx \implies \frac{dx}{x^2} = -du$.

Integral: $\int \sec^2(u)(-du) = -\tan(u) + C$.

Resposta: $-\text{tg}\left(\frac{1}{x}\right) + C$
(g) $\int x \sin(x^2)dx$

Substituição: Seja $u = x^2$.

Diferencial: $du = 2xdx \implies xdx = \frac{du}{2}$.

Integral: $\int \sin(u)\frac{du}{2} = \frac{1}{2}(-\cos(u)) + C = -\frac{1}{2}\cos(u) + C$.

Resposta: $-\frac{1}{2}\cos(x^2) + C$
(h) $\int x^2 e^{x^3}dx$

Substituição: Seja $u = x^3$.

Diferencial: $du = 3x^2dx \implies x^2dx = \frac{du}{3}$.

Integral: $\int e^u\frac{du}{3} = \frac{1}{3}e^u + C$.

Resposta: $\frac{1}{3}e^{x^3} + C$
(i) $\int (3x-2)^{20}dx$

Substituição: Seja $u = 3x-2$.

Diferencial: $du = 3dx \implies dx = \frac{du}{3}$.

Integral: $\int u^{20}\frac{du}{3} = \frac{1}{3} \cdot \frac{u^{21}}{21} + C = \frac{u^{21}}{63} + C$.

Resposta: $\frac{(3x-2)^{21}}{63} + C$
(j) $\int (3t+2)^{2,4}dt$

Substituição: Seja $u = 3t+2$.

Diferencial: $du = 3dt \implies dt = \frac{du}{3}$.

Integral: $\int u^{2{,}4}\frac{du}{3} = \frac{1}{3} \cdot \frac{u^{3{,}4}}{3{,}4} + C = \frac{u^{3{,}4}}{10{,}2} + C = \frac{5}{51}u^{17/5} + C$.

Resposta: $\frac{5}{51}(3t+2)^{17/5} + C$
(k) $\int (x+1)\sqrt{2x+x^2}dx$

Substituição: Seja $u = 2x+x^2$.

Diferencial: $du = (2+2x)dx = 2(x+1)dx \implies (x+1)dx = \frac{du}{2}$.

Integral: $\int \sqrt{u}\frac{du}{2} = \frac{1}{2} \int u^{1/2}du = \frac{1}{2} \left( \frac{u^{3/2}}{3/2} \right) + C = \frac{1}{3}u^{3/2} + C$.

Resposta: $\frac{1}{3}(2x+x^2)^{3/2} + C$
(l) $\int \sec^2(2\theta)d\theta$

Substituição: Seja $u = 2\theta$.

Diferencial: $du = 2d\theta \implies d\theta = \frac{du}{2}$.

Integral: $\int \sec^2(u)\frac{du}{2} = \frac{1}{2}\tan(u) + C$.

Resposta: $\frac{1}{2}\text{tg}(2\theta) + C$
(m) $\int \frac{dx}{5-3x}$

Substituição: Seja $u = 5-3x$.

Diferencial: $du = -3dx \implies dx = -\frac{du}{3}$.

Integral: $\int \frac{1}{u}\left(-\frac{du}{3}\right) = -\frac{1}{3}\ln|u| + C$.

Resposta: $-\frac{1}{3}\ln|5-3x| + C$
(n) $\int u\sqrt{1-u^2}du$

Substituição: Seja $v = 1-u^2$ (usamos $v$ para não confundir com a variável $u$).

Diferencial: $dv = -2udu \implies udu = -\frac{dv}{2}$.

Integral: $\int \sqrt{v}\left(-\frac{dv}{2}\right) = -\frac{1}{2} \int v^{1/2}dv = -\frac{1}{2} \left(\frac{v^{3/2}}{3/2}\right) + C = -\frac{1}{3}v^{3/2} + C$.

Resposta: $-\frac{1}{3}(1-u^2)^{3/2} + C$
(o) $\int \sin(\pi t)dt$

Substituição: Seja $u = \pi t$.

Diferencial: $du = \pi dt \implies dt = \frac{du}{\pi}$.

Integral: $\int \sin(u)\frac{du}{\pi} = \frac{1}{\pi}(-\cos(u)) + C = -\frac{1}{\pi}\cos(u) + C$.

Resposta: $-\frac{1}{\pi}\cos(\pi t) + C$
(p) $\int e^x \sin(e^x)dx$

Substituição: Seja $u = e^x$.

Diferencial: $du = e^xdx$.

Integral: $\int \sin(u)du = -\cos(u) + C$.

Resposta: $-\cos(e^x) + C$
(q) $\int \frac{e^u}{(1-e^u)^2}du$

Substituição: Seja $v = 1-e^u$.

Diferencial: $dv = -e^udu \implies e^udu = -dv$.

Integral: $\int \frac{-dv}{v^2} = -\int v^{-2}dv = -\left(\frac{v^{-1}}{-1}\right) + C = \frac{1}{v} + C$.

Resposta: $\frac{1}{1-e^u} + C$
(r) $\int \frac{\sin\sqrt{x}}{\sqrt{x}}dx$

Substituição: Seja $u = \sqrt{x} = x^{1/2}$.

Diferencial: $du = \frac{1}{2}x^{-1/2}dx = \frac{dx}{2\sqrt{x}} \implies \frac{dx}{\sqrt{x}} = 2du$.

Integral: $\int \sin(u)(2du) = 2\int \sin(u)du = -2\cos(u) + C$.

Resposta: $-2\cos(\sqrt{x}) + C$
(s) $\int e^x\sqrt{1+e^x}dx$

Substituição: Seja $u = 1+e^x$.

Diferencial: $du = e^xdx$.

Integral: $\int \sqrt{u}du = \int u^{1/2}du = \frac{u^{3/2}}{3/2} + C = \frac{2}{3}u^{3/2} + C$.

Resposta: $\frac{2}{3}(1+e^x)^{3/2} + C$
(t) $\int \frac{dx}{ax+b}$ $(a\neq0)$

Substituição: Seja $u = ax+b$.

Diferencial: $du = adx \implies dx = \frac{du}{a}$.

Integral: $\int \frac{1}{u}\left(\frac{du}{a}\right) = \frac{1}{a}\ln|u| + C$.

Resposta: $\frac{1}{a}\ln|ax+b| + C$
(u) $\int (x^2+1)(x^3+3x)^4dx$

Substituição: Seja $u = x^3+3x$.

Diferencial: $du = (3x^2+3)dx = 3(x^2+1)dx \implies (x^2+1)dx = \frac{du}{3}$.

Integral: $\int u^4\frac{du}{3} = \frac{1}{3} \cdot \frac{u^5}{5} + C = \frac{u^5}{15} + C$.

Resposta: $\frac{(x^3+3x)^5}{15} + C$
(v) $\int e^{\cos t}\sin t dt$

Substituição: Seja $u = \cos t$.

Diferencial: $du = -\sin t dt \implies \sin t dt = -du$.

Integral: $\int e^u(-du) = -\int e^udu = -e^u + C$.

Resposta: $-e^{\cos t} + C$
(x) $\int \frac{tg^{-1}x}{1+x^2}dx$

Substituição: Seja $u = \text{tg}^{-1}x$.

Diferencial: $du = \frac{1}{1+x^2}dx$.

Integral: $\int u du = \frac{u^2}{2} + C$.

Resposta: $\frac{1}{2}(\text{tg}^{-1}x)^2 + C$
