1. $\int_{0}^{2} (6x^2 - 4x + 5) \, dx$

Solução Detalhada:

Passo 1: Determinar a primitiva $F(x)$ integrando termo a termo

$$\int (6x^2 - 4x + 5) \, dx = 6 \cdot \frac{x^3}{3} - 4 \cdot \frac{x^2}{2} + 5x = 2x^3 - 2x^2 + 5x$$

Passo 2: Aplicar o Teorema Fundamental do Cálculo no intervalo $[0, 2]$

$$F(2) = 2(2)^3 - 2(2)^2 + 5(2) = 2(8) - 2(4) + 10 = 16 - 8 + 10 = 18$$ $$F(0) = 2(0)^3 - 2(0)^2 + 5(0) = 0$$

Passo 3: Calcular $F(2) - F(0)$

$$\int_{0}^{2} (6x^2 - 4x + 5) \, dx = 18 - 0 = 18$$
Resultado Final: $18$
2. $\int_{1}^{3} (1 + 2x - 4x^3) \, dx$

Solução Detalhada:

Passo 1: Obter a primitiva $F(x)$

$$\int (1 + 2x - 4x^3) \, dx = x + 2 \cdot \frac{x^2}{2} - 4 \cdot \frac{x^4}{4} = x + x^2 - x^4$$

Passo 2: Avaliar nos limites $x = 3$ e $x = 1$

$$F(3) = 3 + (3)^2 - (3)^4 = 3 + 9 - 81 = -69$$ $$F(1) = 1 + (1)^2 - (1)^4 = 1 + 1 - 1 = 1$$

Passo 3: Aplicar $F(3) - F(1)$

$$\int_{1}^{3} (1 + 2x - 4x^3) \, dx = -69 - 1 = -70$$
Resultado Final: $-70$
3. $\int_{-2}^{0} \left( \frac{1}{2}t^4 + \frac{1}{4}t^3 - t \right) \, dt$

Solução Detalhada:

Passo 1: Integrar a expressão polinomial

$$F(t) = \frac{1}{2} \cdot \frac{t^5}{5} + \frac{1}{4} \cdot \frac{t^4}{4} - \frac{t^2}{2} = \frac{t^5}{10} + \frac{t^4}{16} - \frac{t^2}{2}$$

Passo 2: Substituir os limites de integração $t = 0$ e $t = -2$

$$F(0) = 0$$ $$F(-2) = \frac{(-2)^5}{10} + \frac{(-2)^4}{16} - \frac{(-2)^2}{2} = \frac{-32}{10} + \frac{16}{16} - \frac{4}{2} = -\frac{16}{5} + 1 - 2 = -\frac{21}{5}$$

Passo 3: Calcular $F(0) - F(-2)$

$$\int_{-2}^{0} \left( \frac{1}{2}t^4 + \frac{1}{4}t^3 - t \right) \, dt = 0 - \left( -\frac{21}{5} \right) = \frac{21}{5}$$
Resultado Final: $\frac{21}{5} = 4{,}2$
4. $\int_{0}^{3} (1 + 6w^2 - 10w^4) \, dw$

Solução Detalhada:

Passo 1: Determinar a antiderivada $F(w)$

$$F(w) = w + 6 \cdot \frac{w^3}{3} - 10 \cdot \frac{w^5}{5} = w + 2w^3 - 2w^5$$

Passo 2: Avaliar os limites de integração

$$F(3) = 3 + 2(3)^3 - 2(3)^5 = 3 + 2(27) - 2(243) = 3 + 54 - 486 = -429$$ $$F(0) = 0$$
Resultado Final: $-429$
5. $\int_{0}^{2} (2x - 3)(4x^2 + 1) \, dx$

Solução Detalhada:

Passo 1: Expandir o produto algébrico no integrando

$$(2x - 3)(4x^2 + 1) = 8x^3 + 2x - 12x^2 - 3 = 8x^3 - 12x^2 + 2x - 3$$

Passo 2: Integrar o polinômio resultante

$$F(x) = 8 \cdot \frac{x^4}{4} - 12 \cdot \frac{x^3}{3} + 2 \cdot \frac{x^2}{2} - 3x = 2x^4 - 4x^3 + x^2 - 3x$$

Passo 3: Substituir os limites $[0, 2]$

$$F(2) = 2(2)^4 - 4(2)^3 + (2)^2 - 3(2) = 2(16) - 4(8) + 4 - 6 = 32 - 32 + 4 - 6 = -2$$ $$F(0) = 0$$
Resultado Final: $-2$
6. $\int_{-1}^{1} t(1 - t)^2 \, dt$

Solução Detalhada:

Passo 1: Expandir o produto notável e multiplicar por $t$

$$(1 - t)^2 = 1 - 2t + t^2 \implies t(1 - 2t + t^2) = t - 2t^2 + t^3$$

Passo 2: Integrar termo a termo

$$F(t) = \frac{t^2}{2} - \frac{2t^3}{3} + \frac{t^4}{4}$$

Passo 3: Aplicar os limites $t = 1$ e $t = -1$

$$F(1) = \frac{1}{2} - \frac{2}{3} + \frac{1}{4} = \frac{6 - 8 + 3}{12} = \frac{1}{12}$$ $$F(-1) = \frac{(-1)^2}{2} - \frac{2(-1)^3}{3} + \frac{(-1)^4}{4} = \frac{1}{2} + \frac{2}{3} + \frac{1}{4} = \frac{6 + 8 + 3}{12} = \frac{17}{12}$$ $$F(1) - F(-1) = \frac{1}{12} - \frac{17}{12} = -\frac{16}{12} = -\frac{4}{3}$$
Resultado Final: $-\frac{4}{3}$
7. $\int_{0}^{\pi} (5e^x + 3\sin x) \, dx$

Solução Detalhada:

Passo 1: Integrar usando as regras imediatas ($\int e^x dx = e^x$ e $\int \sin x dx = -\cos x$)

$$F(x) = 5e^x - 3\cos x$$

Passo 2: Avaliar em $x = \pi$ e $x = 0$

$$F(\pi) = 5e^\pi - 3\cos(\pi) = 5e^\pi - 3(-1) = 5e^\pi + 3$$ $$F(0) = 5e^0 - 3\cos(0) = 5(1) - 3(1) = 2$$

Passo 3: Calcular $F(\pi) - F(0)$

$$(5e^\pi + 3) - 2 = 5e^\pi + 1$$
Resultado Final: $5e^\pi + 1$
8. $\int_{1}^{2} \left( \frac{1}{x^2} - \frac{4}{x^3} \right) \, dx$

Solução Detalhada:

Passo 1: Reescrever com expoentes negativos

$$\int_{1}^{2} (x^{-2} - 4x^{-3}) \, dx$$

Passo 2: Aplicar a regra da potência

$$F(x) = \frac{x^{-1}}{-1} - 4 \cdot \frac{x^{-2}}{-2} = -\frac{1}{x} + \frac{2}{x^2}$$

Passo 3: Substituir os limites $x = 2$ e $x = 1$

$$F(2) = -\frac{1}{2} + \frac{2}{2^2} = -\frac{1}{2} + \frac{2}{4} = 0$$ $$F(1) = -\frac{1}{1} + \frac{2}{1^2} = -1 + 2 = 1$$ $$F(2) - F(1) = 0 - 1 = -1$$
Resultado Final: $-1$
9. $\int_{1}^{4} \frac{4 + 6u}{\sqrt{u}} \, du$

Solução Detalhada:

Passo 1: Dividir cada termo do numerador por $\sqrt{u} = u^{1/2}$

$$\frac{4 + 6u}{u^{1/2}} = 4u^{-1/2} + 6u^{1 - 1/2} = 4u^{-1/2} + 6u^{1/2}$$

Passo 2: Integrar as potências de $u$

$$F(u) = 4 \cdot \left( \frac{u^{1/2}}{1/2} \right) + 6 \cdot \left( \frac{u^{3/2}}{3/2} \right) = 8\sqrt{u} + 4u\sqrt{u}$$

Passo 3: Avaliar nos limites $[1, 4]$

$$F(4) = 8\sqrt{4} + 4(4)\sqrt{4} = 8(2) + 16(2) = 16 + 32 = 48$$ $$F(1) = 8\sqrt{1} + 4(1)\sqrt{1} = 8 + 4 = 12$$ $$F(4) - F(1) = 48 - 12 = 36$$
Resultado Final: $36$
10. $\int_{0}^{4} (3\sqrt{t} - 2e^t) \, dt$

Solução Detalhada:

Passo 1: Reescrever $\sqrt{t} = t^{1/2}$ e integrar

$$F(t) = 3 \cdot \left( \frac{t^{3/2}}{3/2} \right) - 2e^t = 2t\sqrt{t} - 2e^t$$

Passo 2: Substituir os limites $t = 4$ e $t = 0$

$$F(4) = 2(4)\sqrt{4} - 2e^4 = 8(2) - 2e^4 = 16 - 2e^4$$ $$F(0) = 2(0)\sqrt{0} - 2e^0 = 0 - 2(1) = -2$$

Passo 3: Subtrair $F(4) - F(0)$

$$(16 - 2e^4) - (-2) = 18 - 2e^4$$
Resultado Final: $18 - 2e^4$
11. $\int_{0}^{1} x(\sqrt[3]{x} + \sqrt[4]{x}) \, dx$

Solução Detalhada:

Passo 1: Distribuir $x$ com os expoentes fracionários

$$x(x^{1/3} + x^{1/4}) = x^{1 + 1/3} + x^{1 + 1/4} = x^{4/3} + x^{5/4}$$

Passo 2: Integrar pela regra da potência

$$F(x) = \frac{x^{4/3 + 1}}{\frac{4}{3} + 1} + \frac{x^{5/4 + 1}}{\frac{5}{4} + 1} = \frac{x^{7/3}}{\frac{7}{3}} + \frac{x^{9/4}}{\frac{9}{4}} = \frac{3}{7}x^{7/3} + \frac{4}{9}x^{9/4}$$

Passo 3: Avaliar nos limites $[0, 1]$

$$F(1) = \frac{3}{7}(1) + \frac{4}{9}(1) = \frac{27 + 28}{63} = \frac{55}{63}$$ $$F(0) = 0$$
Resultado Final: $\frac{55}{63}$
12. $\int_{1}^{4} \frac{\sqrt{y} - y}{y^2} \, dy$

Solução Detalhada:

Passo 1: Separar em duas frações simples

$$\frac{\sqrt{y}}{y^2} - \frac{y}{y^2} = y^{1/2 - 2} - \frac{1}{y} = y^{-3/2} - \frac{1}{y}$$

Passo 2: Integrar termo a termo

$$F(y) = \frac{y^{-3/2 + 1}}{-\frac{3}{2} + 1} - \ln|y| = \frac{y^{-1/2}}{-\frac{1}{2}} - \ln|y| = -\frac{2}{\sqrt{y}} - \ln|y|$$

Passo 3: Substituir os limites $y = 4$ e $y = 1$

$$F(4) = -\frac{2}{\sqrt{4}} - \ln(4) = -\frac{2}{2} - \ln(4) = -1 - \ln(4)$$ $$F(1) = -\frac{2}{\sqrt{1}} - \ln(1) = -2 - 0 = -2$$ $$F(4) - F(1) = (-1 - \ln 4) - (-2) = 1 - \ln 4$$
Resultado Final: $1 - \ln(4)$
13. $\int_{1}^{2} \frac{x^2 - 2}{x} \, dx$

Solução Detalhada:

Passo 1: Dividir o numerador por $x$

$$\frac{x^2 - 2}{x} = \frac{x^2}{x} - \frac{2}{x} = x - \frac{2}{x}$$

Passo 2: Encontrar a antiderivada

$$F(x) = \frac{x^2}{2} - 2\ln|x|$$

Passo 3: Avaliar nos limites $x = 2$ e $x = 1$

$$F(2) = \frac{2^2}{2} - 2\ln(2) = 2 - 2\ln(2)$$ $$F(1) = \frac{1^2}{2} - 2\ln(1) = \frac{1}{2} - 0 = \frac{1}{2}$$ $$F(2) - F(1) = \left( 2 - 2\ln 2 \right) - \frac{1}{2} = \frac{3}{2} - 2\ln 2$$
Resultado Final: $\frac{3}{2} - 2\ln(2)$
14. $\int_{\pi/4}^{\pi/3} \csc^2 \theta \, d\theta$

Solução Detalhada:

Passo 1: Identificar a antiderivada direta ($\frac{d}{d\theta}[-\cot\theta] = \csc^2\theta$)

$$F(\theta) = -\cot \theta$$

Passo 2: Avaliar nos limites trigonométricos

$$F(\pi/3) = -\cot(\pi/3) = -\frac{\sqrt{3}}{3}$$ $$F(\pi/4) = -\cot(\pi/4) = -1$$

Passo 3: Calcular $F(\pi/3) - F(\pi/4)$

$$\left( -\frac{\sqrt{3}}{3} \right) - (-1) = 1 - \frac{\sqrt{3}}{3} = \frac{3 - \sqrt{3}}{3}$$
Resultado Final: $\frac{3 - \sqrt{3}}{3}$
15. $\int_{0}^{\pi/4} \frac{1 + \cos^2 \theta}{\cos^2 \theta} \, d\theta$

Solução Detalhada:

Passo 1: Simplificar o integrando usando secante

$$\frac{1 + \cos^2 \theta}{\cos^2 \theta} = \frac{1}{\cos^2 \theta} + \frac{\cos^2 \theta}{\cos^2 \theta} = \sec^2 \theta + 1$$

Passo 2: Integrar cada termo

$$F(\theta) = \tan \theta + \theta$$

Passo 3: Substituir os limites $[0, \pi/4]$

$$F(\pi/4) = \tan(\pi/4) + \frac{\pi}{4} = 1 + \frac{\pi}{4}$$ $$F(0) = \tan(0) + 0 = 0$$
Resultado Final: $1 + \frac{\pi}{4}$
16. $\int_{0}^{\pi/3} \frac{\sin \theta + \sin \theta \tan^2 \theta}{\sec^2 \theta} \, d\theta$

Solução Detalhada:

Passo 1: Fatorar $\sin\theta$ no numerador e aplicar a identidade $1 + \tan^2\theta = \sec^2\theta$

$$\sin \theta (1 + \tan^2 \theta) = \sin \theta \cdot \sec^2 \theta$$

Passo 2: Simplificar a fração

$$\frac{\sin \theta \cdot \sec^2 \theta}{\sec^2 \theta} = \sin \theta$$

Passo 3: Integrar $\sin\theta$ no intervalo $[0, \pi/3]$

$$F(\theta) = -\cos \theta$$ $$F(\pi/3) = -\cos(\pi/3) = -\frac{1}{2}$$ $$F(0) = -\cos(0) = -1$$ $$F(\pi/3) - F(0) = -\frac{1}{2} - (-1) = \frac{1}{2}$$
Resultado Final: $\frac{1}{2}$
17. $\int_{1}^{64} \frac{1 + \sqrt[3]{x}}{\sqrt{x}} \, dx$

Solução Detalhada:

Passo 1: Converter radicais para expoentes fracionários e dividir

$$\frac{1 + x^{1/3}}{x^{1/2}} = x^{-1/2} + x^{1/3 - 1/2} = x^{-1/2} + x^{-1/6}$$

Passo 2: Integrar pela regra das potências

$$F(x) = \frac{x^{1/2}}{1/2} + \frac{x^{5/6}}{5/6} = 2\sqrt{x} + \frac{6}{5}x^{5/6}$$

Passo 3: Avaliar em $x = 64$ e $x = 1$

$$F(64) = 2\sqrt{64} + \frac{6}{5}(64)^{5/6} = 2(8) + \frac{6}{5}(2^5) = 16 + \frac{6}{5}(32) = 16 + \frac{192}{5} = \frac{272}{5}$$ $$F(1) = 2\sqrt{1} + \frac{6}{5}(1)^{5/6} = 2 + \frac{6}{5} = \frac{16}{5}$$ $$F(64) - F(1) = \frac{272}{5} - \frac{16}{5} = \frac{256}{5}$$
Resultado Final: $\frac{256}{5} = 51{,}2$
18. $\int_{0}^{\sqrt{3}/2} \frac{dr}{\sqrt{1 - r^2}}$

Solução Detalhada:

Passo 1: Reconhecer a derivada da função arco seno ($\frac{d}{dr}[\arcsin r] = \frac{1}{\sqrt{1-r^2}}$)

$$F(r) = \arcsin(r)$$

Passo 2: Avaliar nos limites $r = \frac{\sqrt{3}}{2}$ e $r = 0$

$$F\left(\frac{\sqrt{3}}{2}\right) = \arcsin\left(\frac{\sqrt{3}}{2}\right) = \frac{\pi}{3}$$ $$F(0) = \arcsin(0) = 0$$
Resultado Final: $\frac{\pi}{3}$
19. $\int_{1}^{2} \frac{(x - 1)^3}{x^2} \, dx$

Solução Detalhada:

Passo 1: Expandir o cubo do binômio no numerador

$$(x - 1)^3 = x^3 - 3x^2 + 3x - 1$$

Passo 2: Dividir cada termo por $x^2$

$$\frac{x^3 - 3x^2 + 3x - 1}{x^2} = x - 3 + \frac{3}{x} - x^{-2}$$

Passo 3: Integrar termo a termo

$$F(x) = \frac{x^2}{2} - 3x + 3\ln|x| + \frac{1}{x}$$

Passo 4: Avaliar nos limites $[1, 2]$

$$F(2) = \frac{4}{2} - 3(2) + 3\ln(2) + \frac{1}{2} = 2 - 6 + \frac{1}{2} + 3\ln(2) = -\frac{7}{2} + 3\ln(2)$$ $$F(1) = \frac{1}{2} - 3(1) + 3\ln(1) + 1 = \frac{1}{2} - 3 + 0 + 1 = -\frac{3}{2}$$ $$F(2) - F(1) = \left( -\frac{7}{2} + 3\ln 2 \right) - \left( -\frac{3}{2} \right) = -\frac{4}{2} + 3\ln 2 = 3\ln(2) - 2$$
Resultado Final: $3\ln(2) - 2$
20. $\int_{0}^{1/\sqrt{3}} \frac{t^2 - 1}{t^4 - 1} \, dt$

Solução Detalhada:

Passo 1: Fatorar o denominador como diferença de dois quadrados

$$t^4 - 1 = (t^2 - 1)(t^2 + 1)$$

Passo 2: Simplificar a fração eliminando o fator comum $(t^2 - 1)$

$$\frac{t^2 - 1}{(t^2 - 1)(t^2 + 1)} = \frac{1}{t^2 + 1}$$

Passo 3: Integrar a função arco tangente

$$F(t) = \arctan(t)$$

Passo 4: Avaliar nos limites $t = \frac{1}{\sqrt{3}}$ e $t = 0$

$$F\left(\frac{1}{\sqrt{3}}\right) = \arctan\left(\frac{1}{\sqrt{3}}\right) = \frac{\pi}{6}$$ $$F(0) = \arctan(0) = 0$$
Resultado Final: $\frac{\pi}{6}$
